# Audio Assets

PC·모바일 웹 데모용 런타임 BGM과 절차적 효과음이다. 현재 BGM 2곡은 사용자가 제공한 MP3 원본을
그대로 사용하며, 효과음 12종은 `scripts/generate-audio-assets.mjs`의 오실레이터·엔벌로프·
결정적 노이즈로 생성한다.

## 런타임 규격

- BGM: MP3, 48,000 Hz, stereo
- SFX: RIFF/WAVE PCM, 22,050 Hz, 16-bit, mono
- BGM: 에셋별 사운드 마커의 `startSeconds`~`endSeconds` 구간을 Phaser에서 무한 반복
- 효과음: 동작의 실제 확정 시점에 1회 재생
- 재생 볼륨: 에셋별 기본 게인 × 사용자가 저장한 BGM/SFX 볼륨. 신규 기본값은 BGM 45%·SFX 38%
- 자동 재생: 브라우저 정책에 따라 첫 사용자 입력 뒤 시작

## BGM

| 파일 | 길이 | 적용 화면 |
| --- | ---: | --- |
| `bgm/game-theme-v1.mp3` | 원본 69.96초 · 재생 0.90~68.06초 | 로그인·캐릭터 화면과 살아 있는 보스가 없는 모든 맵 |
| `bgm/boss-theme-v1.mp3` | 원본 52.28초 · 재생 0~51.99초 | 중간·상위·최종 보스 등장부터 처치 완료까지 |

모든 화면과 일반 맵은 같은 `GameTheme` 키를 공유하므로 화면·맵 전환 때 곡이 재시작되지
않는다. 살아 있는 보스가 생성되면 `BossTheme`으로 전환하고, 처치 보상 확정 뒤 일반곡으로
복귀하며, 보스가 재생성되면 보스곡도 다시 시작한다. Phaser 사운드 마커는 원본 파일을
변경하지 않고 앞·뒤 무음만 재생 구간에서 제외해 첫 소리와 반복 사이 공백을 줄인다.

초기 로딩에는 일반 BGM과 SFX만 포함한다. 보스 MP3는 살아 있는 중간·상위·최종 보스가 있는
맵에 처음 진입할 때 동적으로 한 번 요청하며, 준비 중에는 일반곡을 계속 재생한다. 같은 요청은
합쳐지고 한 번 성공한 오디오는 이후 보스 맵에서 캐시를 재사용한다. 실패하면 다음 보스 조우에서
다시 시도하며, 이미 맵을 떠났거나 보스를 처치한 뒤 끝난 요청은 보스곡으로 전환하지 않는다.

## 생성과 권리

- BGM 원본: 사용자가 제공한 `메이플 스토리.mp3`, `메이플스토리 오오.mp3`; 런타임 파일은
  재인코딩 없이 원본 바이트를 보존한다.
- BGM 권리: 제공 파일의 저작권·배포 허가는 확인되지 않았다. 로컬 데모 외부에 공개하기
  전 권리자가 허용한 이용 범위를 사용자가 확인해야 한다.
- SFX 제작자: 이 프로젝트의 절차적 생성 스크립트. 외부 원본·샘플·음원을 사용하지 않는다.
- SFX 재생성: `npm run assets:audio`. 고정 음표·파형과 seed로 같은 PCM을 만든다.
- 기존 절차적 BGM WAV 3종은 생성 스크립트의 이전 출력으로 저장소에 남아 있지만 런타임에서
  import하지 않으며 `dist/`에도 포함하지 않는다.
- 배포 감사에서는 런타임 BGM MP3 2곡을 8,000,000-byte 총량 계산에서 제외하되 산출물에는
  포함하고, JavaScript 개별 상한은 그대로 적용한다.

전체 에셋 출처와 배포 정책은 [`ASSET_CREDITS.md`](../../ASSET_CREDITS.md)를 따른다.
