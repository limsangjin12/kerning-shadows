# Combat UI Assets

## 데미지 숫자 아틀라스

`damage-numbers-v1.svg`는 32×32 셀을 10열×4행으로 배치한 자체 제작 픽셀 숫자 아틀라스다.

- 1행: 일반 몬스터 피해 — 노란색
- 2행: 강한 공격 피해 — 주황색
- 3행: 플레이어 피격 — 빨간색
- 4행: 크리티컬 몬스터 피해 — 밝은 아이보리 숫자와 분홍 그림자
- 각 행의 프레임 순서: 숫자 `0`부터 `9`
- 배경: 투명

다음 명령으로 동일한 파일을 다시 만들 수 있다.

```bash
node scripts/generate-damage-atlas.mjs
```

숫자 모양은 외부 폰트나 기존 게임 리소스에 의존하지 않는 3×5 픽셀 매트릭스다.

## 원펀맨 주먹 충격파

`one-punch-shockwave-v1.svg`는 원펀맨이 주먹을 뻗은 뒤 손앞에서 발사되는 192×96 방향성
공기 충격파다. 외부 이미지와 표창 프레임을 사용하지 않은 자체 제작 투명 SVG이며, 1페이즈의
청백색 단일 파동과 체력 50% 이하 2페이즈의 금백색 3방향 파동이 색·크기만 바꾸어 공유한다.
